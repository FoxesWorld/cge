## 🎨 Features

- **Modular** architecture via plugins & modules  
- **PBR‑Ready**: Physically Based Rendering out of the box  
- **Multi‑Threaded** asset loading & management  
- **Config‑Driven** formats (`.cgmat`, `.cgtex`, etc.)
